# 🛒 ECOMZY – Full Stack E-Commerce Application

A modern and responsive shopping cart application built using **React** and **Tailwind CSS**.  
ECOMZY demonstrates dynamic product rendering, cart management, and clean component-based architecture.

## ✨ Features

- ⚡ Optimized Rendering with React
- 🎨 Modern UI using Tailwind CSS

- **State Management:** Context API / useState
